# Loan Approval Prediction Using Machine Learning

## 📌 Project Description
This is a minor project that uses Machine Learning to predict whether a loan application may be approved or rejected based on applicant data.

The project is developed using Python and Jupyter Notebook.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Project Files
- `loan_approval.ipynb` – Jupyter Notebook containing the project code.
- `loan_approval_data.csv` – Dataset used for analysis and model training.

## ⚙️ How to Run
1. Download or clone this repository.
2. Install the required libraries:
   ```bash
   pip install pandas numpy scikit-learn matplotlib seaborn
   ```
3. Open `loan_approval.ipynb` in Jupyter Notebook.
4. Run the cells in order.

## 🎯 Objective
To understand and apply Machine Learning techniques for loan approval prediction using applicant data.
